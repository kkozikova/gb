TOY APP

NFT trading platform

TOY is a WEB3 Ecosystem focusing on games. Each of these titles has it's own sets of collectables, special events and about pages. The task is to create a simple and "light" style to make ease the trading experience for the user. Make it more, intuitive and comfortable to use while keeping in all the options present on trading platforms.

This project is currently under development.

TAIX AI

AI Streamer and streaming assistant.

Created visual identity for an intelligent streaming AI, co-devloped with AWS innovation labs. Worked on interfaces taking note of the set Twitch framework ,which would seamlessly incorporate the TAIX plugin, both directly on Twitch and on the TAIX AI website. TAIX's design is calm, friendly and inviting, made to be as simple as can be. It's aim is to make the WEB3 space more accessible to the general public.

TAIX is currently being developed.

QORPO WORLD

WEB3 ecosystem of games and AI products.

Qorpo World is a WEB3 ecosystem focusing on finance, games and AI products. Each of these titles has it's own sets of collectables, special events and about pages. The website consists of game showcases, social media quest sections- the "community hub, user's crypto wallet and the qorpo spinner."

This design is currently being programmed on front-end and will be deployed soon.
