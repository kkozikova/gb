TOY APP

Entertainment network and publisher

TOY is an entertainment ecosystem with web3 features ,focusing on games. Each of these titles has it's own sets of collectables, special events and about pages. The task is to create a minimal and intuitive style to make ease the trading experience for the user. Make it more, intuitive and comfortable to use while keeping in all the options present on trading platforms.

This project is currently under development.

TAMITOS

IP built to support awareness about mental health in chilren

Tamitos is an IP focused on spreading awareness about mental health, specifically autism and down syndrome in children. My role was to create a UI that is easy to navigate and visually fits with the set identity of the Tamitos Brand: Scribbles, doodles and colorful characters. The project is relatively data-heavy , so it was a challenge to bring all of the information forward in a clear manner.

TAIX AI

AI Streamer and streaming assistant.

Created visual identity for an intelligent streaming AI, co-devloped with AWS innovation labs. Worked on interfaces taking note of the set Twitch framework ,which would seamlessly incorporate the TAIX plugin, both directly on Twitch and on the TAIX AI website. TAIX's design is calm, friendly and inviting, made to be as simple as can be. It's aim is to make the WEB3 space more accessible to the general public.
